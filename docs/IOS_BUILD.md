# iOS build and signing

This environment is Linux. It cannot run Xcode 26, sign an archive, or install the app on an iPhone. The project is ready for a Mac.

## What is in the tree

- `capacitor.config.ts`: app id `com.cagefreecapital.pshop`, app name PShop, `webDir` `dist/client`, no remote server URL.
- `ios/`: Capacitor 7.4.3 Swift Package Manager project.
- Deployment target iOS 17. iPhone only (`TARGETED_DEVICE_FAMILY = 1`).
- `ios/App/App/Info.plist`: camera and photo-library purpose strings, `ITSAppUsesNonExemptEncryption` false.
- `ios/App/App/PrivacyInfo.xcprivacy`: no tracking; photos, other user content, and user id for app functionality; required-reason API declarations for UserDefaults (`CA92.1`), file timestamps (`C617.1`), disk space (`E174.1`), and system boot time (`35F9.1`).
- `ios/App/App/App.entitlements`: Sign in with Apple, Default.
- `ios/App/App/PShopStorePlugin.swift`: returns no products. It is not StoreKit.
- Marketing version `0.1.0`, build number `1`.

`ios/App/CapApp-SPM/Package.swift` is generated by `npx cap sync ios`. It points at the pnpm paths for Camera, Share, Haptics, Filesystem, App, Splash Screen, Status Bar, Sign in with Apple, and secure storage. Run sync again on the Mac after `pnpm install` so those paths match that machine.

## Mac steps

1. Install Xcode 26 or newer, open it once, and accept the license. As of October 26, 2026, App Store uploads require Xcode 26 and the iOS 26 SDK. Check Apple’s SDK minimum again on the day you upload. The app’s deployment target stays iOS 17 until a device test says otherwise.
2. `git clone` the repository. `corepack pnpm install --frozen-lockfile`.
3. `node scripts/stage-recognition.mjs`
4. `node scripts/fetch-model.mjs` and confirm `models/CHECKSUMS.sha256` matches the files.
5. `npm run build:ios` (`PSHOP_STATIC_EXPORT=1` is set by that script). Confirm `dist/client/index.html` exists and `dist/client/vendor/transformers/transformers.js` and `dist/client/models/SmolVLM-256M-Instruct/onnx/vision_encoder_q4.onnx` exist.
6. `npx cap sync ios`
7. Open `ios/App/App.xcodeproj` in Xcode.
8. Select the App target. Signing: Team = the Apple Developer team. Automatically manage signing. Bundle id must match the identifier registered in the developer portal and the App Store Connect app record.
9. On the App ID, enable Sign in with Apple. Xcode should pick up `App/App.entitlements`. If the capability is missing, add it in Signing & Capabilities. Do not commit certificates, profiles, or `.p8` keys.
10. Replace `PShopStorePlugin.swift` with a StoreKit 2 implementation before offering Plus. Until then the paywall stays unavailable, which is the intended state.
11. Product → Archive. Distribute to App Store Connect. Save the archive, the dSYM, the marketing version, the build number, and the git commit together.
12. On a development iPhone, run the same scheme and walk `docs/TESTFLIGHT.md` before you treat recognition as shippable.

`pod install` is not required for this SPM project. Do not add CocoaPods unless a future plugin has no `Package.swift`.
